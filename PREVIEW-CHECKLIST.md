# External preview acceptance — not yet observed

One record per real receiving pair/environment. Never fill acceptance from mock tests. This form contains no session IDs, credentials or message content.

Before live sessions, the extracted package can run a model-free self-test: `runtime/node.exe scripts/acceptance.mjs <new absolute test directory>`. It starts two isolated native-socket stubs and its own helpers, observes question/reply IDs, and stops those helpers. It refuses an existing directory and retains a redacted acceptance-report.json. Passing this does **not** fill the actual-app/user observations below.

Use one urgent question per direction and one restart sample; don't send repeated acknowledgements to measure speed. Record saved, transport-accepted and actual observed-receipt times separately. AI response latency is not relay latency. Receive/check the exact original IDs before completing them.

Start with the owner's separate test conversations, then at least two additional independent users or machines. Public support claims follow those observations, not the number of local tests.
